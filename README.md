# FluentPro AI

FluentPro AI is a modern AI-powered spoken English learning application designed for Indian professionals.

The app focuses on:
- spoken English fluency
- business communication
- pronunciation improvement
- confidence building
- real-time AI conversation practice

---

# Features

## Learn Mode
Users can:
- listen to English sentences
- read Hindi translations
- learn vocabulary meanings
- improve pronunciation
- practice sentence repetition

---

## Practice Conversation Mode
Users can:
- speak with AI using microphone
- type messages manually
- receive AI voice responses
- view live subtitles
- improve fluency naturally
